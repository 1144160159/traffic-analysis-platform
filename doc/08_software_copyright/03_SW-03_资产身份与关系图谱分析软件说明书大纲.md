## 3. 必须写实的核心旅程

1. **人工资产原子写入**：权限→校验→幂等/锁→资产/history/audit/outbox/ledger→commit。
2. **观测事实更新**：观测来源→来源优先级→revision→事件，不覆盖受保护治理字段。
3. **资产事件到图投影**：Kafka→inbox→实体/关系upsert→watermark。
4. **有界图查询**：权限→预算→实体/邻居/路径→continuation或安全失败。

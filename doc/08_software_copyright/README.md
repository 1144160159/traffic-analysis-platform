## 4. 法规锚点

- [《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)第七条要求软件独立开发或取得原著作权人许可；第九至十一条规定申请表、程序和一种文档鉴别材料及权属证明等主要材料。
- 一般交存的程序和文档通常分别取前、后各连续30页；不足60页时提交全部。页数是鉴别材料抽取规则，不是把同一系统机械拆成九件的依据。
- 本规划是项目内部工程和材料方案，不构成法律意见；递交前须按登记机构当期线上表单和材料要求复核。

- 本目录是写作和材料形成方案，不表示九件软件已经完成登记。
- M00–M13、212个父任务和1289个原子PR属于工程治理结构，不是软著作品数量。
- 详细设计中的 `TARGET/GAP/DRAFT/BLOCKED/NOT_EXECUTED` 内容不得写成V1.0已经实现。
- 性能、算法、CNAS、生产HA/DR等尚未闭环的指标不得进入“已实现成果”。
- 每个生产源文件最终只能归属一件作品；共享接口只作为依赖说明。

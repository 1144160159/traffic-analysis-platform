## 3. 必须写实的核心旅程

1. **Flow到Session/Feature**：事件校验→event time→keyBy→状态/窗口→会话和特征输出。
2. **Feature到Detection/Alert**：规则/模型版本读取→匹配→Detection→告警生成。
3. **日志和用户行为处理**：独立Topic→规范化→状态分析→投影/DLQ。
4. **故障恢复**：checkpoint成功→作业故障→同UID/serializer恢复→不重复或可解释重放。

## 3. 必须写实的核心旅程

1. **告警到研判事实**：告警事件→inbox→权威/投影→列表/详情快照→人工状态。
2. **告警到证据/战役/攻击链**：证据引用→专题/战役→攻击链快照→逐事实下钻。
3. **反馈到治理handoff**：TP/FP→history/audit/outbox→白名单或规则/模型复审接口。
4. **多存储降级**：某投影不可用→partial/stale envelope→保留权威状态→恢复对账。

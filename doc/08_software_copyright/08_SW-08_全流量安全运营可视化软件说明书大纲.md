## 3. 必须写实的核心旅程

1. **登录到告警研判**：登录→态势→告警→详情/证据→反馈或白名单草案。
2. **资产到图谱分析**：资产列表→详情→关系/路径→关联告警或取证。
3. **规则/模型发布观察**：规则或模型→审批/部署状态→ACK→回滚请求。
4. **取证任务**：任务创建→accepted/running→完成/partial→校验和下载。

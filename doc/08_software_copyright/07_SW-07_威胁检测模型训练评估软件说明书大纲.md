## 3. 必须写实的核心旅程

1. **手工训练**：提交参数→数据抽取/切分→训练→评估→解释→ONNX→登记请求。
2. **评估未通过**：评估结果不满足事前配置门→阻断登记/激活→保留失败产物→新run重试。
3. **模型交接**：模型和metadata→MinIO/hash→Registry API→登记receipt→交给SW-06审批。
4. **工作流失败恢复**：阶段失败→定位日志和artifact→按幂等边界重试→不覆盖已冻结run。

## 5. 禁止声明

- 不宣称准确率95%、误报率低于5%或CNAS通过。
- 不宣称未知攻击/GNN已经完成，除非冻结代码和证据确实存在。
- 不把训练集、小样本或内部F1写成任务书验收结论。
- 不把模型登记等同于审批、激活或在线部署。
- `register_model.py`只作为SW-06 API客户端，不主张后端治理实现。

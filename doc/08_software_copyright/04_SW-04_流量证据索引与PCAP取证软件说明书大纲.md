## 3. 必须写实的核心旅程

1. **索引事件到可查询记录**：Kafka record→校验→转换→批量写→checkpoint。
2. **告警上下文到取证任务**：五元组/时间窗→权限→任务→索引→对象清单→完成或partial。
3. **受控下载**：对象身份→size/hash→授权→下载→审计。
4. **故障恢复**：对象缺失/错hash/服务重启→任务保持可查询→安全重试或明确失败。

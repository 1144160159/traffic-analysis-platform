## 3. 必须写实的核心旅程

1. **用户登录授权**：密码/OIDC→用户映射→JWT→中间件→tenant/scope→业务授权。
2. **API Token生命周期**：创建→只显示一次→hash存储→校验→轮换/撤销→审计。
3. **身份事件审计**：身份命令→审计事件/outbox→Kafka→materializer→PG查询。
4. **越权拒绝**：错误tenant/scope/对象→fail closed→safe message→审计。

## 3. 必须写实的核心旅程

1. **规则草案到发布**：创建→验证→审批→权威事务/outbox→消费者ACK→完成。
2. **模型登记到激活**：artifact/评估引用→审批→consumer-ready→激活事件→ACK。
3. **灰度与回滚**：小范围启用→观察阈值→扩展或停止→恢复上一不可变版本。
4. **部分ACK恢复**：部分消费者失败→保持未完成→重试/停止扩展→最终对账。

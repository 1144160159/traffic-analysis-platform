## 使用边界

- 已购买且平台允许导出的文件，可以在单位内部授权范围内整理、校验和存储。
- 平台只允许在线阅读时，不抓取正文、不截图拼接、不移除 DRM。
- 所谓“试读后 24 小时内删除”、网盘分享或不明 PDF 聚合站，不构成版权方授权。
- 需要完整正文时，应由采购、图书馆或已有正版账户取得；资料库只记录来源，不保存账户凭据。

## 与项目规范的关系

图书用于解释方法与案例，不直接作为强制验收标准。项目的硬性 UI 基线应以 WCAG 2.2、WAI-ARIA、ARIA APG 和项目选定的中性设计令牌为准；本目录的《Web UI 栅格、尺寸与组件状态规范速查》给出可直接执行的最小基线。

## 0. 本卷如何使用(读法)

- 每个函数一张"函数卡",字段对齐 `code-unit-contract.schema.json`;`body_steps` 每步带 `guard/reads/writes/invokes/invariant_before/invariant_after/error_ids/cancel_point/oracle_ids`。
- 实现者只允许实现本卷列出的函数;新增函数必须先补卡(ENG-FUNC-006)。
- 错误 ID 命名空间:`ATC-<域>-ERR-<NNN>`;oracle ID 命名空间:`<域>-T-<NNN>`(对应测试文件中的测试名)。
- 本卷不覆盖:APT/攻击链/GNN/CEP/四源/取证/PDF(已悬挂)。

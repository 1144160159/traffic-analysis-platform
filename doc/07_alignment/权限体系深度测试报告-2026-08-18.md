## 2. 契约 143 操作全量运行时断言

主体:viewer(traffic-ui 令牌,realm 角色 traffic-viewer,9 scope)与 admin(traffic-ui 令牌,traffic-admin)。逐操作请求(模板段替换样本值),断言:
- viewer 无 required_scope 的操作 → 必须 401/403(契约层 AUTHZ_403 或业务层 403)
- viewer 有 scope 的操作 → 不得 401/403(可到业务层 2xx/4xx)
- admin 对 GET 只读操作 → 不得 401/403

结果(178 操作):**0 真实异常**。两处"异常"为测试台误报并已复核:
- `POST /internal/v1/audit/batches` → 405:网关仅放行方法白名单,内部端点不对公网可达(设计正确,无暴露)
- `GET /v1/alerts/{id}/evidence/{id}/download` → 403(双主体):该端点要求 expires+signature 短时签名票据(handler 层纵深),矩阵未携带票据;viewer/admin 均先通过 alert:read 检查再被票据闸拒绝(设计正确)

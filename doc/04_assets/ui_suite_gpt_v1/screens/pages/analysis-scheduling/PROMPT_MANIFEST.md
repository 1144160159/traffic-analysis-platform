## 每页增量提示词

1. `analysis-task-management-20260816.png`

   > 当前高亮任务管理。标题区右侧唯一主按钮“新建任务定义”；说明保存定义不会开始分析。展示定义/负责人、目标摘要、当前批准方案、有效调度、最近运行、生命周期和服务端允许操作；不得出现实时五段进度或模型结果。

2. `analysis-schedule-management-20260816.png`

   > 当前高亮调度管理。标题区右侧唯一主按钮“新建调度计划”；列表分别展示任务定义、已批准方案来源与 exact revision、触发方式/规则、下次触发、最近物化结果、调度生命周期和操作。暂停提示固定为只停止未来触发，不影响已物化任务和正在运行的分析。

3. `analysis-orchestration-20260816.png`

   > 当前高亮任务编排。左侧为不可变版本列表，中间只显示固定五段和低调的 PlanReady/Reconcile 技术闸门，右侧按需配置 Drawer 展示 exact revision/hash、输入输出合同、重试和兼容性。禁止自由连线、删除阶段或把人读报告拖入流程。

4. `analysis-run-monitor-20260816.png`

   > 当前高亮运行监控。标题区唯一主按钮“发起即时分析”；三项摘要为运行中、需关注、今日完成。筛选为搜索、RunState、方案来源、触发方式、时间。每行一个 Run，分别展示方案、触发、状态/五段、机器结论、风险严重度、证据完整性/校验和服务端允许操作；默认无常驻右栏。

5. `analysis-on-demand-wizard-20260816.png`

   > 隐藏工作区“发起即时分析”，三步为任务与范围、方案、校验并提交。最后一步明确 TriggerKind 固定 ON_DEMAND；默认方案与自定义方案二选一并解释默认不代表自动触发。展示 preflight、兼容性、资源影响、有效期和最终主按钮“提交并开始分析”。

6. `analysis-run-detail-20260816.png`

   > 独立单 Run 详情，不保留左侧 Run 列表。顶部显示任务名、Task/Run 短 ID、权威 RunState、更新时间和允许动作；只出现一条五段 Steps。概览分别展示范围与计划、机器结论、最高风险、Completeness、IntegrityState、关键发现/限制和独立 HumanReport 状态。

7. `analysis-resource-management-20260816.png`

   > 管理员页面，当前高亮调度资源。三项摘要为队列积压、租约健康、执行器就绪；四个 Tab 为容量配额、队列、租约、执行器。表格只回答阻塞位置、影响 Run、状态和下一动作，不绘制资源拓扑大屏；UNKNOWN 不得显示健康。

8. `analysis-report-center-20260816.png`

   > 一级菜单分析报告下的报告中心。机器摘要与人读报告为两个独立 Tab；机器摘要表显示 Run 终态、FindingConclusion、Completeness/IntegrityState、冻结时间和 summary hash。人读报告状态不修改 RunState，只有 AVAILABLE 提供下载。

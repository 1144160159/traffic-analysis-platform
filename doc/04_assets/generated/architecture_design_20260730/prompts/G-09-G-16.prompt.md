# G-09～G-16 ImageGen九段式提示词

本文件引用并继承同目录下的 [`00-统一视觉母版.md`](./00-统一视觉母版.md)。逐图提示词只定义该图特有的目的、时态、布局、节点、连线、禁止关系、文字和验收条件；未重复说明的画布、语义色、节点形状、连线语义、全局禁止关系与全局验收要求，以统一视觉母版为准。

为避免把双向交互误解为无语义双向关系，以下 `A ↔ B [TYPE]` 在渲染时表示两条可辨认的有向边 `A → B [TYPE]` 与 `B → A [TYPE]`，不得画成无箭头直线。当前批次仅形成提示词，暂不生成图片。

- `manifest.md`：图号、文件、提示词、状态、哈希与适用章节索引。

## 事实与时态

架构图分为 `AS-IS`、`TRANSITION` 和 `TARGET`。图中的目标链路不表示当前生产已经落地。当前态只能由仓库静态证据或候选绑定的运行证据证明；性能、HA、DR与生产可用性不得由图片推导。

## 制图策略

整套图采用“少量短标签＋编号节点＋图外精确图例”。ImageGen负责布局、层次、颜色和方向表达；精确业务含义以提示词总册、节点表、连线表和评审记录为准。任何图片若出现白名单外节点、错误连线或把目标态画成当前态，均不得标记为通过。
